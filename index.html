Herdr 是一個 agent 多工器（agent multiplexer）——官方一句話定位： 「Herdr 之於 coding agent，就像 tmux 之於終端機」。同時開好幾個 Claude Code / Codex 時， 它讓你在一個終端機裡看清楚：誰在跑、誰卡住等你、誰做完了；而且蓋上筆電，agent 照樣繼續跑。

🐑 01 > 認識 HERDR：AI 代理的牧羊人

把每一隻 coding agent 想成一隻羊：放出去工作後各忙各的，沒有牧羊人時你得一個視窗一個視窗巡。 Herdr（= herder，牧羊人）把整群羊圈進同一個終端機，側欄一眼告訴你—— 哪隻在吃草（working）、哪隻咩咩叫等你開門（blocked）、哪隻吃飽趴著了（done）。

它不是
NOT
不是終端機模擬器——Ghostty / iTerm / Kitty 照常用，Herdr 是在裡面跑的 TUI；也不是網頁儀表板——沒有網頁、沒有帳號、沒有雲端控制台。
它是
YES
「聽得懂 agent」的 tmux：持久會話 + 可點擊窗格 + agent 狀態辨識 + 自動化 API。單一 Rust 執行檔，免註冊帳號、無遙測。
⚡ Linux / macOS 穩定版；Windows 目前為預覽測試版
能力tmux / Zellij桌面 Agent AppHERDR
直接在你的終端機裡跑✓—✓
關掉視窗後程序仍存活（持久 PTY）✓有限✓
從遠端 SSH 接回同一個畫面✓有限✓
看得懂 agent 狀態（工作中 / 卡住 / 完成）—部分✓
單獨接上某一隻 agent 的終端機——✓
agent 可反過來指揮它（CLI + JSON API）可寫指令稿部分✓
和 tmux 最大的差別：tmux 只看到「一個程序」，Herdr 看得懂「這隻 agent 現在需不需要你」。 tmux 很會養程序但不懂 agent；桌面 App 懂 agent 卻離不開那台有螢幕的電腦——Herdr 兩邊都要。
⚡ 02 > 安裝與啟動：五分鐘讓羊群進牧場

選一種你熟悉的安裝方式就好。裝完之後，啟動 Herdr 只需要打一個字：herdr。

STEP 1 > 安裝（擇一）
# 指令稿（Linux / macOS，最快）
$ curl -fsSL https://herdr.dev/install.sh | sh

# Homebrew
$ brew install herdr

# mise
$ mise use -g herdr

# Windows（預覽測試版）
PS> irm https://herdr.dev/install.ps1 | iex
STEP 2 > 啟動與驗證
$ cd ~/my-project
$ herdr

這一行做了很多事：Herdr 會啟動（或接上）一個背景伺服器、自動開好第一個工作區。 你不用管 socket 或伺服器細節——之後就算你離開，agent 也會繼續跑。 如果 shell 說找不到 herdr，重開終端機或確認安裝目錄在 PATH 裡。

STEP 3 > 放第一隻羊進來
$ claude   # 或 codex、opencode、pi、copilot …任選
# 側欄馬上出現這隻 agent，並開始顯示牠的狀態

在窗格裡照平常的方式啟動 coding agent，Herdr 會自動認出牠。 支援自動偵測的包括 Claude Code、Codex、Pi、OpenCode、GitHub Copilot CLI、Cursor、Droid、Amp 等； 沒列到的一樣能當普通終端機程式跑，只是狀態資訊比較陽春。

之後怎麼更新？
$ herdr update               # 指令稿 / 手動安裝的人用這個
$ herdr channel set preview  # 搶先試預覽版
$ herdr channel set stable   # 換回穩定版
# Homebrew / mise 安裝的人，改用各自的套件管理器更新
小提醒：更新如果動到「客戶端 / 伺服器通訊協定」，Herdr 會問你要不要停掉舊伺服器。 停掉會結束窗格裡的程序，所以挑羊群都閒著的時機：herdr server stop 之後重新 herdr。
🧱 03 > 核心概念：五層樂高 + 狀態燈號

Herdr 的世界只有五種積木，由外往內一層包一層：Session → Workspace → Tab → Pane → Agent。 用牧場比喻一次記起來。

SESSION 會話整座牧場：背景伺服器，燈永遠亮著
WORKSPACE 工作區一個圍欄 = 一個專案（官方建議：一個 repo 一欄）
TAB 分頁圍欄裡的分區：agents / logs / server / review
PANE 窗格一格柵欄 = 一個真正的終端機（真實 PTY），離線後照樣活著
AGENT 代理住在柵欄裡的羊：窗格是「地點」，agent 是「住客」，可以空著也可以換人住
為什麼「一個專案一個工作區」？因為狀態是「往上彙整」的——工作區會匯總裡面所有 agent 的狀態， 一個專案一欄，你才看得出是哪個專案在等你。

客戶端 vs 伺服器——為什麼關筆電羊還在？ Herdr 拆成兩半：伺服器擁有所有窗格與程序（住在背景）；客戶端只是你眼前的終端機介面。 按 Ctrl+B Q 把客戶端「摘掉」（detach），伺服器和所有 agent 完全不受影響。 直接關掉終端機視窗效果也一樣——都只是摘掉客戶端。

會話的生與死
$ herdr               # 接上（或啟動）預設 session
# Ctrl+B 再按 Q → 摘掉客戶端，一切照跑
$ herdr               # 隨時接回來，畫面跟離開時一樣
$ herdr server stop   # 真的要收工：停伺服器，程序也會結束

五種 agent 狀態——這是 Herdr 的靈魂功能，側欄燈號的意義：

狀態意思你要做什麼
working正在吃草：agent 埋頭工作中。放著，先去忙別的專案。
blocked咩咩叫等你：出現批准 / 提問 UI，需要你做決定。最優先處理，會把整個工作區染紅。
done做完了、但你還沒去看。去驗收；看過那個分頁後轉為 idle。
idle待命：事情看過了、也沒人在跑。不用理。
unknown認不出這個程序的狀態。當普通終端機用即可。
彙整規則（由強到弱）：blocked > working > done > idle。狀態從窗格 → 分頁 → 工作區一路往上滾， 掃一眼側欄就知道該先去哪個專案。
done 和 idle 最容易搞混：底層是同一種「閒下來」，差別只在你看過了沒—— 而且用 CLI 讀輸出不算看過。
blocked 的判定刻意保守：只有畫面明確出現已知的批准 / 提問 UI 才標 blocked； 偵測只影響顯示與等待，絕不會替你按同意。
⌨️ 04 > 指令速查：鍵盤、CLI、遠端

所有快捷鍵都是「前綴鍵」模式：先按 Ctrl+B，下一個鍵才是給 Herdr 的命令。 其實滑鼠就能做完所有事——點窗格聚焦、拖邊框調大小、右鍵開選單、拖曳選字即複製；鍵盤只是進階選配。

按鍵（先按 Ctrl+B）動作
V向右分割窗格
−向下分割窗格
C開新分頁
N / P切換下一個 / 上一個分頁
Shift+N開新工作區
W導覽模式：在專案（工作區）之間跳來跳去
Q摘離（detach）：摘掉客戶端，agent 照跑
常用 CLI
# 會話
$ herdr                        # 接上（或啟動）預設 session
$ herdr session list           # 列出具名 session
$ herdr session attach work    # 完全獨立的另一套環境
$ herdr server stop            # 收工：停伺服器（程序會結束）

# Agent
$ herdr agent attach reviewer  # 不開整個介面，只接上一隻 agent
$ herdr agent start reviewer --kind codex --pane w1:p2
$ herdr agent prompt reviewer "審查目前的 diff" --wait
$ herdr agent read reviewer --source recent-unwrapped
$ herdr integration install claude  # 提升狀態偵測品質

# Pane（普通程序用這組，不是 agent 也能自動化）
$ herdr pane split --current --direction right
$ herdr pane run w1:p3 "just test"
$ herdr pane wait-output w1:p3 --regex "passed|failed"
agent 指揮 agent：所有「建立類」指令都回傳 JSON，指令稿（或另一隻 agent）可以照 「開窗格 → 啟動 agent → 派工 → 等狀態 → 讀結果」的流程指揮整個牧場。 注意 agent start 不會自己開窗格——窗格是地點、agent 是住客，要先用 pane split 準備好。
遠端模式指令特色
本機herdr最日常：羊養在自己電腦。
SSH 上去跑ssh you@server 再 herdr像 tmux 的經典做法，手機 SSH App 也適用。
原生遠端接入herdr --remote workbox本機薄客戶端：沿用本機快捷鍵、剪貼簿橋接（連圖片都能貼過去）、遠端沒裝還會幫你裝。
外掛市集（150+ 社群外掛）
$ herdr plugin install <owner>/<repo>
# 上架只要在 GitHub repo 加上 herdr-plugin topic，市集自動收錄
