⬡ 01 > 語言伺服器類 LSP

讓 Claude 能直接呼叫語言伺服器，取得真實的型別資訊、錯誤診斷、定義跳轉——而不只是「看程式碼猜測」。

csharp-lsp
C#
Roslyn / OmniSharp 整合，診斷錯誤、跳轉定義、完整型別資訊。
typescript-lsp
TypeScript
TS 官方語言伺服器，型別檢查、自動補全診斷。
clangd-lsp
C / C++
clangd 整合，C/C++ 靜態分析與精確型別推斷。
pyright-lsp
Python
Microsoft Pyright，Python 靜態型別推斷與診斷。
⬡ 02 > 瀏覽器自動化類
chrome-devtools-mcp
Chrome + Puppeteer
直接操控 Chrome DevTools，可截圖、監控網路請求、分析效能、自動化操作網頁。
⚡ 偏重 DevTools 層級的深度除錯
playwright
Chrome / Firefox / Safari
用 Playwright 控制多種瀏覽器，適合跨瀏覽器 UI 測試與自動化流程。
⚡ 偏重跨瀏覽器自動化測試
兩者差異：chrome-devtools-mcp 能存取 DevTools 內部 API（效能分析、記憶體快照），playwright 勝在跨瀏覽器與 CI 整合。可以同時裝，視需求選用。
⬡ 03 > 知識查詢類
context7
Documentation
即時查詢任何函式庫的最新文件與範例程式碼，避免 Claude 使用過時 API，讓回答永遠基於最新版本。
